# Number Systems

- **Binary** represents numbers using the digits 0 and 1.
- **Decimal** represents numbers with ten digits, from 0 to 9.
- **Hexadecimal** uses sixteen symbols, from 0 to 9 and A to F.
- **Octal** uses eight digits, from 0 to 7.
- **Place value** is the contribution of a digit based on its position in a number.
- **Bit** is a single binary digit.
